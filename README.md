# 📖 책표지 퀴즈 (cover_quiz)

지정한 라이브러리의 도서 표지 이미지를 보여주고, 객관식(오답 3개)으로
책 제목을 맞히는 BookOasis 카테고리 게임 플러그인입니다.

- **버전**: 1.0.0
- **플러그인 ID**: `cover_quiz`
- **표시명**: 책표지 퀴즈

## 주요 기능

- 표지 이미지를 그대로 보여주고, 정답 1개 + 오답 3개(기본값, 설정으로 2~6개 조절 가능) 중 하나를 고르는 객관식 퀴즈입니다.
- 설정 화면에서 **개별 라이브러리(예: general 스코프 아래의 "텍스트 소설", "텍스트 일반", "텍스트 무협" 등)를 드롭다운으로 직접 선택**합니다. 드롭다운은 스코프별로 그룹핑되며, 목록은 설정 화면을 열 때마다 실제 DB에서 조회한 실제 라이브러리명으로 채워집니다. 비워두면 카테고리 메뉴를 열었을 때 활성화된 현재 라이브러리를 사용합니다.
- 좌측/상단 **카테고리 내비게이션**의 "책표지 퀴즈" 메뉴에 자체 제작한 풀페이지 UI(표지 이미지 + 선택지 버튼 + 정오답 피드백 + 점수판 + 진행률 바)로 노출됩니다. 헤더 부제에 현재 어떤 라이브러리로 퀴즈 중인지 실제 이름이 표시됩니다.
- 정답을 고르면 정답 선택지가 초록색으로, 오답을 골랐다면 고른 선택지가 빨간색으로 표시되고 정답도 함께 강조됩니다.
- 라운드가 끝나면 최종 점수와 "다시 시작" 버튼이 있는 결과 화면이 나옵니다.
- **리더보드(선택 기능)**: 설정에 Google Apps Script 웹 앱 URL을 등록하면, 퀴즈 화면(문제 풀이 중)과 결과 화면 모두에서 문제 풀이 영역 바로 아래에 상시 순위표(시간 · 닉네임 · 점수, 최대 10명)가 표시됩니다. 라운드 종료 후 닉네임을 입력하고 "기록 저장" 버튼으로 점수를 저장하면 순위표가 즉시 갱신됩니다. URL을 등록하지 않으면 이 UI 자체가 나타나지 않습니다.
- 환경설정 화면은 평소엔 접혀 있다가 클릭해야 펼쳐지는 커스텀 폼(`settings.html`/`settings.css`)을 사용합니다.

## 설치 방법

```bash
cd /BookOasis_stable/plugins/metadata
rm -rf cover_quiz/
mkdir cover_quiz
# 이 저장소의 파일들을 cover_quiz/ 폴더에 복사
docker compose restart bookoasis
```

재시작 후, 환경설정 > 플러그인 설정에서 "책표지 퀴즈"를 활성화하고
아래 설정값을 입력합니다. 설정 항목들은 기본적으로 접혀 있으니
"설정 펼치기"를 클릭해서 펼친 뒤 입력하세요.

## 설정 항목

| 키 | 설명 | 기본값 |
| --- | --- | --- |
| `TARGET_DB_TYPE` | 퀴즈에 사용할 라이브러리 (드롭다운에서 선택, 내부적으로 `스코프:라이브러리ID` 형식으로 저장됨). 비워두면 현재 활성 라이브러리 사용 | (비어있음) |
| `QUESTIONS_PER_ROUND` | 한 라운드 문제 수 | `10` |
| `CHOICES_COUNT` | 선택지 개수 (정답 1개 포함) | `4` |
| `APPS_SCRIPT_URL` | 리더보드 저장용 Google Apps Script 웹 앱 URL. 기본값이 미리 채워져 있으며, 비워두면 리더보드 UI 자체가 비활성화됩니다 | (아래 기본 URL) |

## 리더보드(Google 스프레드시트) 설정 방법

1. 새 Google 스프레드시트를 만듭니다.
2. 주소창 URL(`https://docs.google.com/spreadsheets/d/여기가ID/edit`)에서 스프레드시트 ID를 복사합니다.
3. 상단 메뉴 **확장 프로그램 > Apps Script**를 엽니다.
4. 기본 코드를 모두 지우고 이 저장소의 `apps_script.gs` 파일 내용 전체를 붙여넣습니다.
5. 파일 상단의 `var SPREADSHEET_ID = "여기에_스프레드시트_ID를_붙여넣으세요";`에 2번에서 복사한 ID를 붙여넣습니다.
6. 우측 상단 **배포 > 새 배포**를 클릭합니다.
   - 유형: **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **전체**
7. 배포 후 나오는 웹 앱 URL(`.../exec`로 끝남)을 복사합니다.
8. BookOasis 플러그인 설정의 `APPS_SCRIPT_URL`에 이 URL을 붙여넣고 저장합니다.

스프레드시트에는 `leaderboard`라는 시트가 자동으로 생성되고, `timestamp`,
`name`, `library`, `score`, `total` 컬럼으로 매 저장마다 한 줄씩 쌓입니다.
라이브러리별로 순위가 나뉘므로, 다른 라이브러리로 퀴즈를 풀면 그 라이브러리
기준 순위표가 따로 보입니다.

> Apps Script 웹 앱은 브라우저에서 직접 호출하므로, "액세스 권한이 있는
> 사용자"를 반드시 **전체**로 설정해야 합니다. "나만" 또는 "조직 내"로
> 설정하면 저장/조회가 실패합니다.
>
> `SPREADSHEET_ID`를 채우지 않고 배포하면
> `{"success":false,"error":"..."}` 형태로 명확한 안내 메시지가
> 반환됩니다 — `getActiveSpreadsheet()`는 웹 앱 실행 컨텍스트에서
> null을 반환할 수 있어(바인딩 여부와 무관하게 불안정) ID로 직접
> 여는 방식을 사용합니다.

## 라이브러리 드롭다운은 어떻게 채워지나요?

BookOasis의 DB 스코프 식별자는 4개(`general`/`adult`/`audiobook`/`video`)로
고정되어 있고, 각 스코프 안에 여러 개별 라이브러리가 있습니다
(`books.library_id`로 구분). 설정 화면(`settings.html`)에 내장된 스크립트가
페이지를 열 때마다 `cover_quiz.py`의 `get_dashboard_data()` 응답에 포함된
`library_options`를 조회해서, 4개 스코프 전체에서 실제 라이브러리명을
가져와 드롭다운을 `<optgroup>`으로 그룹핑해 채웁니다.

라이브러리명은 각 스코프의 DB에서 `libraries`(또는 `library`) 테이블의
`name`/`display_name`/`library_name`/`title` 컬럼을 순서대로 방어적으로
탐색해서 가져옵니다(`_list_libraries_in_scope()`). 정확한 스키마를 미리
알 수 없어 여러 후보를 시도하는 방식이므로, 드롭다운이 비어 있거나
목록이 이상하게 나온다면 실제 라이브러리명이 저장된 테이블/컬럼명을
알려주시면 후보 목록에 정확히 맞춰 수정할 수 있습니다.

이 조회는 요청 querystring에 `list_only=1`이 붙었을 때만 실행되고
(설정 화면 전용), 일반 퀴즈 화면 요청에서는 완전히 건너뜁니다. 그래야
설정 화면을 열 때마다 무거운 "현재 라이브러리 전체 도서 조회+셔플"
로직까지 함께 실행되어 느려지는 문제가 없습니다.

**속도 안전장치 (3중)**
1. 4개 스코프를 순차가 아니라 병렬로 조회하고, 스코프 하나당 5초가
   지나면 그 스코프는 건너뜁니다 (`SCOPE_TIMEOUT_SEC`). 응답이 없는
   스코프 하나 때문에 전체가 멈추지 않습니다.
2. 도서 목록 조회 쿼리 자체에 `LIMIT 3000`을 걸어둡니다. `list_only`
   감지가 어떤 이유로 실패해서 무거운 경로를 타더라도, 라이브러리 크기와
   무관하게 조회가 빠르게 끝나도록 하는 안전망입니다.
3. 설정 화면(`settings.html`)의 fetch 요청 자체에도 10초 타임아웃을
   걸어서, 서버가 정말 응답을 못 주는 극단적인 경우에도 화면이 "불러오는
   중..."에 무한정 멈춰있지 않고 에러 메시지가 표시됩니다.

그래도 계속 느리거나 응답이 없다면, 진단박스(있다면)의 내용이나 서버
로그의 `[cover_quiz]` 태그 라인, 또는 브라우저 개발자도구 Network 탭에서
`cover_quiz/data?list_only=1` 요청의 상태/소요 시간을 확인해서 알려주시면
원인을 더 정확히 좁힐 수 있습니다.

## 표지 이미지 URL 관련 안내 (중요)

`books.cover_image` 컬럼에는 (다른 메타데이터 플러그인들의 `apply()`
저장 로직 기준으로) `"{library_id}/{파일명}.webp"` 형태의 **상대경로**가
저장되어 있는 것으로 확인했습니다. 이 플러그인은 이 값 앞에 `/covers/`
접두사를 붙여 이미지 URL로 사용합니다 (예: `/covers/3/book_ab12.webp`).

만약 실제 서버에서 표지 파일이 다른 경로(예: `/api/media/covers/`)로
서비스되고 있다면, `cover_quiz.py` 상단의 `COVER_URL_PREFIX` 상수만
실제 값으로 바꿔주시면 됩니다. 설치 후 표지 이미지가 깨져서 보인다면
이 부분을 가장 먼저 확인해주세요.

```python
# cover_quiz.py
COVER_URL_PREFIX = "/covers/"
```

## 문제 해결 (트러블슈팅)

1. **플러그인이 환경설정 > 플러그인 설정 목록에 아예 안 보임**
   - 서버 로그에서 `[MetadataFactory] Plugin load failed (cover_quiz): ...` 같은 줄이 있는지 확인하세요.
   - `category_tab`은 반드시 고정된 `dict`여야 합니다. `@property`처럼 동적으로 계산하는 방식은 플러그인이 목록에서 통째로 사라지는 원인이 될 수 있습니다.
2. **설정 화면의 라이브러리 드롭다운이 "(현재 카테고리의 라이브러리 사용)"만 나옴**
   - 라이브러리명이 저장된 테이블/컬럼명이 `_list_libraries_in_scope()`의 후보 목록(`libraries`/`library` 테이블, `name`/`display_name`/`library_name`/`title` 컬럼)과 다를 수 있습니다. 실제 스키마를 알려주시면 정확히 맞춰드리겠습니다.
3. **표지 이미지가 깨져서 보임 (아이콘만 보이거나 로드 실패)**
   - 위 "표지 이미지 URL 관련 안내"를 참고해서 `COVER_URL_PREFIX` 값을 확인/수정하세요.
4. **"표지가 등록된 도서가 부족합니다" 오류가 표시됨**
   - 지정한 라이브러리에 표지(`cover_image`)가 등록된 도서 수가 선택지 개수(`CHOICES_COUNT`)보다 적은 경우입니다. 먼저 메타데이터 플러그인(예: 통합 도서 검색)으로 표지를 채워주세요.
5. **"지정된 라이브러리에 연결할 수 없습니다" 오류가 표시됨**
   - 드롭다운에서 선택한 라이브러리가 저장된 이후 해당 라이브러리가 삭제/이동되었을 수 있습니다. 설정을 다시 열어 드롭다운에서 라이브러리를 재선택해주세요.
6. **리더보드 "기록 저장" 클릭 시 "저장 실패: TypeError: Failed to fetch"**
   - 거의 대부분 Apps Script 배포의 **액세스 권한**이 "전체"가 아니어서 발생합니다. Apps Script URL을 브라우저에서 직접 열었을 때 구글 로그인 화면이 뜬다면 이게 원인입니다 — 배포 관리에서 액세스 권한을 "전체"로 바꾸고 새 버전으로 재배포하세요 (URL이 바뀌면 플러그인 설정도 갱신).
   - 광고 차단/개인정보 보호 브라우저 확장 프로그램이 `script.google.com` 요청을 차단하는 경우도 있습니다. 확장 프로그램을 잠깐 꺼보고 재시도해보세요.

## 파일 구성 및 계약 요약

- `cover_quiz.py`
  - `search()`, `apply()`: 필수 계약이지만 이 플러그인은 게임 전용이라 빈 구현만 제공합니다.
  - `get_dashboard_data()`: `category_tab`의 `script.js`와 `settings.html`의 드롭다운 채우기 스크립트가 공통으로 호출하는 데이터 엔드포인트(`/api/media/dashboard/widgets/cover_quiz/data`)의 실제 구현입니다. 문제 세트(표지 + 선택지 + 정답 여부)와 함께, 설정 화면용 전체 라이브러리 목록(`library_options`)을 항상 포함해서 반환합니다.
  - `category_tab`: 좌측/상단 "카테고리" 내비게이션에 메뉴 항목을 추가합니다. `dashboard_widget`은 정의하지 않았습니다 — 코어의 대시보드 카드 렌더러는 정적인 도서 카드만 그리기 때문에 클릭 인터랙션이 필요한 퀴즈와는 맞지 않습니다.
- `index.html` / `script.js` / `style.css`
  - `category_tab` 클릭 시 로드되는 완전 커스텀 풀페이지 UI입니다. 문제 로드, 선택지 클릭 처리, 정오답 피드백, 점수판, 라운드 종료 후 재시작을 모두 프론트엔드에서 처리합니다.
- `settings.html` / `settings.css`
  - 환경설정 탭 전용 커스텀 폼입니다. 평소엔 `<details>`로 접혀 있다가 "설정 펼치기"를 클릭해야 3개 설정 항목이 나타납니다. 라이브러리 드롭다운은 페이지 로드시 내장 스크립트가 `get_dashboard_data()`를 호출해 실제 라이브러리명으로 동적으로 채웁니다.
- `VERSION`
  - 플러그인 버전 정보 (`{"plugin version": "1.0.0"}`).
